# needs Python 3.13 or 3.14 (no astropy for 3.15 yet)

steps to set up locally:
git clone https://github.com/FabianClaudioMaier/SpaceAppChallenge.git && cd SpaceAppChallenge

Then for the python packages and proper environment:
python -m venv ./python-backend/.venv && source ./python-backend/.venv/bin/activate
pip install -r ./python-backend/requirements.txt
